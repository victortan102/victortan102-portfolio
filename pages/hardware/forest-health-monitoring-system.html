Project Introduction

The Forest Health Monitoring System is an edge computing-based IoT solution designed for real-time environmental monitoring using multi-modal sensing and AI-driven analytics. The system integrates audio, video, and environmental sensors to detect bird species and identify anomalies such as gas fluctuations and temperature changes. By leveraging edge devices for local inference and MQTT for efficient communication, it delivers a low-latency, cost-effective alternative to traditional cloud-dependent monitoring systems, with real-time alerts and an interactive dashboard for visualization.

🗝️ Key Features of Application

  1. Multi-Modal Bird Detection: Detects bird presence and species using both audio (YAMNet) and video (SSD MobileNet V2 + classification models).
  2. Real-Time Environmental Monitoring: Tracks temperature, humidity, eCO2, and TVOC levels using IoT sensors.
  3. Edge-Based Processing: Performs local inference on edge devices to reduce latency and bandwidth usage.
  4. Event-Driven MQTT Communication: Uses MQTT for efficient, real-time data transmission between devices and server.
  5. Anomaly Detection & Risk Classification: Identifies abnormal environmental conditions and classifies risk levels (Low, Medium, High).
  6. Intelligent Alert System: Triggers alerts based on thresholds, spikes, and detected anomalies.
  7. Interactive Web Dashboard: Provides real-time data visualization with charts, alerts panel, and media playback using Flask and Chart.js.
  8. Efficient Data Handling: Implements rolling averages, spike detection, and selective frame transmission to optimize performance.

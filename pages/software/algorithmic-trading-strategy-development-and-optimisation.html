Project Description

This project focuses on the development and optimisation of an enhanced algorithmic trading strategy using large-scale financial data and NLP-based sentiment analysis. By integrating technical indicators such as trend, momentum, and volatility with FinBERT sentiment extracted from earnings call transcripts, the system generates more reliable trading signals while improving risk-adjusted performance. The solution is designed with scalability in mind, leveraging vectorised computations and optimisation techniques to efficiently process millions of data points and deliver robust, generalisable results.

This report for this project was uploaded to arXiv, a free distribution service and an open-access archive for scholarly articles in the fields of physics, mathematics, computer science, quantitative biology, quantitative finance, statistics, electrical engineering and systems science, and economics.

🗝️ Key Features of Application

  1. Multi-Factor Strategy: Combines trend, momentum, volatility, and sentiment indicators to generate robust trading signals
  2. FinBERT Sentiment Analysis: Utilises NLP to extract sentiment from earnings call transcripts for forward-looking insights
  3. Advanced Risk Management: Implements ATR-based dynamic trailing stop-loss to protect capital and reduce drawdowns
  4. Top-N Stock Selection: Applies cross-sectional momentum ranking to select the strongest-performing stocks
  5. Scalable Data Processing: Efficiently handles large-scale datasets (~2 million rows) with optimised pipelines
  6. Optimised Computation: Uses vectorised operations and pre-computed indicators for faster backtesting
  7. Comprehensive Evaluation: Assesses performance using key metrics such as return, Sharpe ratio, drawdown, and volatility

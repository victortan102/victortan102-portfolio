Project Overview

MedicalCare is a full-stack Android healthcare application built using MVVM architecture and Firebase, designed to connect patients and doctors through real-time communication, appointment management, and location-based features. In addition to the functional platform, the project includes a “spy-friendly” malicious variant developed for educational purposes, demonstrating real-world mobile security vulnerabilities such as data exfiltration, keylogging, and stealth techniques. This dual approach showcases both modern mobile app development practices and critical cybersecurity concepts.

🗝️ Key Features of Application

  1. Doctor Discovery & Profiles: Browse and view detailed doctor profiles including specialisation and experience.
  2. Real-Time Chat System: Enables instant messaging between patients and doctors with support for location sharing.
  3. Appointment Management: Allows users to schedule, manage, and track medical appointments efficiently.
  4. Role-Based Access Control: Supports multiple user roles (patient, doctor, admin) with controlled permissions.
  5. Scalable MVVM Architecture: Implements clean separation of concerns using MVVM and repository patterns for maintainability.
  6. Firebase Integration: Utilises Firebase Authentication and Firestore for secure, real-time backend services.
  7. Malicious Variant for Security Learning: Demonstrates real-world threats including data exfiltration, keylogging, GPS tracking, and remote command execution.
  8. Security Evasion Techniques: Incorporates obfuscation, background persistence, and stealth communication to simulate advanced malware behaviour.
  9. Educational Cybersecurity Insights: Highlights risks such as excessive permissions, accessibility abuse, and the need for secure coding practices.
